关于这个原型

这是“贷前人工审核质检优化”解决方案中一致性看板与闭环追踪两个模块的演示原型，针对四个现状痛点：

  1. 抽样只看件、不看人 → 加入审核员行为信号。在静态分层抽样之外，持续计算每位审核员的通过率、与模型分歧率、审核时长及其月末偏移；出现异常时动态提高该审核员的抽检比例。
  2. 质检尺度不一 → 一致性看板。对比不同质检员对同类件的判定差错率，偏离过大时触发交叉复核与尺度校准会。
  3. 反馈滞后、以分组宣导为主 → 差错归因分流。政策理解偏差 → 培训宣导；执行不到位 → 流程与系统控制；为 KPI 动作变形 → 调整考核口径，而不是一味宣导。
  4. 宣导后无人追踪 → 闭环追踪。每次宣导登记主题与日期，自动跟踪同类差错在宣导前后的变化，用数据判断干预是否有效。

本页面为纯前端原型，所有数据均为模拟生成，不代表任何真实机构。
